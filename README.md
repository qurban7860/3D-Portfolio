A high-performance, immersive 3D portfolio designed to push the boundaries of modern web development. Built with **React**, **Three.js**, and **Framer Motion**, this application delivers a cinematic experience while maintaining enterprise-grade performance and accessibility.

---

## ✨ Core Pillars of Excellence

### 🎨 Immersive Visual Experience
- **Cinematic 3D Scenes**: Leveraging `@react-three/fiber` and `@react-three/drei` for interactive, performant 3D visualizations (Computers, Earth, Stars).
- **Glassmorphic Design System**: A bespoke design language featuring high-fidelity transparency, satin-finished borders, and deep mesh gradients.
- **Micro-interactions**: Every button, card, and link is enriched with spring-physics animations and haptic-like visual feedback.

### ⚙️ Enterprise-Grade Architecture
- **Dynamic Content Engine**: A fully custom Admin Dashboard allowing real-time content management (CRUD operations for Projects, Experience, Skills, and more).
- **Instant Synchronization**: Implementation of an optimized state-management layer that reflects CMS changes immediately across the front-end without page refreshes.
- **Robust Asset Resolution**: Intelligent fallback systems for images, icons, and media to ensure the UI never breaks.

### 📱 Flawless Performance & UX
- **Zero-Layout-Shift (ZLS)**: Precise skeleton loaders and pre-rendered transition states.
- **Global Responsiveness**: A fluid layout system that scales from ultra-wide 4K displays to the narrowest mobile devices.
- **SEO & Social Ready**: Integrated dynamic SEO headers and social meta tags for maximum visibility.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/qurban7860/3D-Portfolio.git
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Environment Setup**
   Create a `.env` file in the root and add your keys:
   ```env
   VITE_APP_EMAILJS_SERVICE_ID=your_service_id
   VITE_APP_EMAILJS_TEMPLATE_ID=your_template_id
   VITE_APP_EMAILJS_PUBLIC_KEY=your_public_key
   ```
4. **Start Development Server**
   ```bash
   npm run dev
   ```
