## 🚀 Get Started in Seconds

Ready to deploy your own masterpiece? 

1. **Clone & Install**:
   ```bash
   git clone <repo-url>
   cd 3D-Portfolio
   npm install
   ```

2. **Setup Environment**:
   * Create a `.env` file from the template.
   * Start the engines!

3. **Launch**:
   ```bash
   npm run dev        # Starts the mesmerizing frontend
   npm run dev:server # Fires up the robust backend
   ```
