# 🚀 High-Fidelity 3D Glassmorphic Portfolio

Welcome to the pinnacle of modern portfolio design. This project is a production-grade, full-stack multi-tenant 3D portfolio architected with technical precision and architectural excellence. It combines cutting-edge 3D visuals with a robust administrative backend, specifically engineered to compete at the highest industry levels.

---

## 💎 Premium Design System: Glassmorphism v2.0

This portfolio implements a sophisticated **Glassmorphism** design system, ensuring a state-of-the-art visual experience:

*   **Vibrant Depth**: Multi-layered transparency with high-fidelity background blurs (`backdrop-blur-3xl`).
*   **Dynamic Mesh Backgrounds**: Immersive, animated mesh gradients that provide a "living" atmosphere.
*   **Precision Aesthetics**: Ultra-thin borders (`1px`) with subtle white-to-transparent gradients to simulate realistic glass edges.
*   **Micro-Animations**: Fluid interactions powered by `Framer Motion` and `Three.js` for an interface that feels alive and responsive.
*   **Premium Typography**: Curated font hierarchy using `Inter` and `Outfit` for maximum legibility and professional polish.

### 🌟 Benefits of Glassmorphism
1.  **Hierarchy**: Naturally emphasizes content by separating layers through depth rather than just color.
2.  **Modern Appeal**: Instantly establishes the developer as someone at the forefront of modern UI/UX trends.
3.  **Visual Breathability**: Reduces visual clutter, making complex data sets easier to consume.

## 🛠️ Core Functionality & Features

### 1. **Administrative Command Center (CMS)**
*   **Real-time Content Management**: Update every aspect of your portfolio (Hero, About, Experiences, Projects) instantly without code changes.
*   **Decoupled Architecture**: Dedicated tables for FAQs and Social Links ensure optimized API responses and easier management.
*   **Premium Dashboard UI**: A fully glassmorphic admin terminal featuring system status indicators and intuitive CRUD controls.

### 2. **3D Interactive Experience**
*   **Three.js Integration**: High-performance 3D models and interactive canvases (e.g., Stars, Computers) that respond to user interaction.
*   **Optimized Performance**: Leverages React Three Fiber and Drei for smooth 60FPS animations on modern hardware.

### 3. **Dynamic SEO & Performance**
*   **Auto-SEO**: Built-in meta-tag generation for every page ensuring maximum search engine visibility.
*   **Lightning Fast Navigation**: React-Router-DOM based SPA architecture with optimized loading states to eliminate "flicker".

### 4. **Multi-Tenant Ready**
*   **Tenant Isolation**: Architected to support multiple users, each with their own isolated data and custom URL structure.

---

## 📁 Architecture Summary

*   **Frontend**: `React 18`, `Vite`, `Tailwind CSS`, `Framer Motion`, `Three.js`.
*   **Backend**: `Node.js`, `Express`, `Libsql` (SQLite/Turso).
*   **State Management**: `Context API` for seamless portfolio and authentication synchronization.
*   **Security**: `JWT` based authentication with `Bcrypt` password hashing.

## 🚀 Getting Started

### Installation
1.  Clone the repository.
2.  Run `npm install` in the root directory.
3.  Create a `.env` file based on the provided template.
4.  Run `npm run dev` to start the frontend and `npm run dev:server` for the backend.
